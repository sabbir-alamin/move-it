# 🚚 Move It — Moving Services Website

A clean, responsive landing page for **Move It**, a US-based moving services company. Built with HTML5 and Bootstrap 5.

## ✨ Features

- Responsive navbar with dropdown and postcode search
- Hero section with call-to-action buttons
- Feature highlights (Professional, Countrywide, Personal Touch)
- Image carousel showcasing happy customers
- Multi-column footer with service links
- Mobile-friendly layout via Bootstrap 5

## 🚀 Getting Started

No build tools or dependencies needed — it's pure HTML.

**Option 1 — Open directly:**
```bash
# Just open index.html in your browser
open index.html
```

**Option 2 — Serve locally with Python:**
```bash
python -m http.server 8000
# Then visit http://localhost:8000
```

**Option 3 — VS Code Live Server:**
Install the [Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) and click "Go Live".
